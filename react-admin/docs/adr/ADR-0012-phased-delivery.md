# ADR-0012：分期交付——空白页占位与模板页定调

- 状态：已接受
- 日期：2026-09-23
- 关联：ADR-0010、ADR-0011

## 背景

用户访谈第二轮明确：dashboard 与系统管理页面先用**空白页（仅展示页面名）**代替；后续先挑一个页面实现**固定模板**，再按模板挨个完善其余页面。这一节奏避免了「一次性全量复刻」的返工风险（页面形制未定先铺量）。

## 决策

- **Phase 1（骨架）**：登录链路完整（登录/守卫/动态路由/改密）、布局完整（Header/Sidebar/Logo）、共享层完整（HTTP/Query/stores/utils/icons）、auth mock、AGENTS + 主题文档基线；dashboard 与 system/*（user/role/menu/org/log）全部为空白占位页 `<PlaceholderPage title="..." />`，**但菜单与路由按最终形态先行**（空页已挂真实后端菜单路径）。
- **Phase 2（模板页定调）**：与用户确认首个系统管理页面（建议 `system/user`），完整实现并沉淀：列表页模板形制、ProTable、SelectIcon、useDialogForm、ECharts、`docs/{components, page-conventions}.md`、对应 API 与 mock。
- **Phase 3（逐页完善）**：按 Phase 2 模板逐个替换占位页（role / menu / org / log / dashboard），同步补齐对应 API 与 mock。

## 理由

- 骨架先行保证登录/权限/布局/共享层这些「跨页面不变量」尽早稳定并被验收。
- 模板页定调后，其余页面是批量复制生产，风险与评审成本最低。
- 占位页使菜单/路由/权限过滤在 Phase 1 即可端到端验证。

## 后果

- Phase 1 交付即可登录、按后端菜单进入各空白页、改密、登出，完整验证骨架。
- 替换页面体时路由与菜单不动，Phase 2/3 无需重触动路由层。

## 被否决的备选

- **一次性全量复刻所有页面**：模板未定先铺量，页面形制返工风险高；也违背用户明确选择的交付节奏。
- **只交付工程脚手架（无登录无布局）**：无法端到端验证动态路由与权限过滤，骨架不完整。
